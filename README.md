# Credit Risk & Early-Warning Analytics Platform

An end-to-end banking analytics project focused on **credit risk, customer profitability, loan performance, delinquency, and early-warning analysis**.

The project follows a complete data analytics workflow:

**Raw Data → Python Cleaning → Data Validation → Feature Engineering → MySQL → SQL Analysis → Power BI → Business Insights**



## 📌 Project Overview

Financial institutions need to balance customer profitability with credit risk.

A customer can generate significant profit while simultaneously carrying elevated credit risk. Similarly, a large loan portfolio can generate revenue while creating concentrated credit-loss exposure.

This project analyzes banking data to understand:

- Customer profitability
- Credit risk
- Loan exposure
- Default behavior
- Payment behavior
- Delinquency
- Credit losses
- Early-warning indicators
- High-risk customers
- Profitability versus risk

The objective is to transform raw banking data into actionable business insights using Python, SQL, and Power BI.



# 🎯 Business Problem

The banking institution wants to understand:

1. Which customer segments generate the most profit?
2. Which customers contribute the most to overall profitability?
3. Where is credit risk concentrated?
4. How does default rate vary across risk categories?
5. Which loan types have the largest exposure?
6. Which customers show early-warning signals?
7. How does delinquency relate to default?
8. Which customers are both profitable and high risk?
9. Where is credit-loss exposure concentrated?
10. Which factors should be monitored as part of an early-warning system?


# 🎯 Project Objectives

The main objectives of this project are to:

- Clean and validate a raw banking dataset.
- Identify and handle data-quality issues.
- Engineer business-oriented analytical features.
- Store the cleaned data in MySQL.
- Perform basic, intermediate, and advanced SQL analysis.
- Use joins, subqueries, CTEs, and window functions.
- Analyze customer profitability.
- Analyze loan and credit risk.
- Identify early-warning indicators.
- Build an interactive Power BI dashboard.
- Translate analytical findings into business insights.
