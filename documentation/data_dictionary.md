# Data Dictionary

## Customer Fields

| Field | Description |

| Customer_ID | Unique customer identifier |
| Customer_Name | Customer name |
| Age | Customer age |
| Age_Group | Customer age category |
| Gender | Customer gender category |
| Country | Customer country |
| City | Customer city |
| Customer_Segment | Premium, Standard or Subprime customer segment |
| Employment_Status | Employment category |
| Occupation | Customer occupation |
| Customer_Since | Date the customer relationship began |
| Annual_Income | Customer annual income |
